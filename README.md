# Pure Hide

**Pure Hide** 是一个为 [Obsidian](https://obsidian.md/) 设计的全能界面美化与排版增强插件，整合了**界面隐藏、独立布局、精细排版、圆角材质、毛玻璃效果、交互细节**等 100+ 可配置选项，完全基于 Obsidian 核心变量，自动适配任意主题。

- [GitHub 仓库](https://github.com/yuangwu/obsidian-pure-hide)
- [作者主页](https://github.com/yuangwu)

---

## 📖 简介

Pure Hide 旨在让您能够**一键隐藏干扰元素**，同时精细调整**排版、间距、圆角、透明度和动画**，打造属于您自己的沉浸式写作与阅读环境。所有样式均通过 CSS 变量与 Obsidian 主题无缝融合，无需额外 CSS 片段。

## ✨ 功能概览

- **🙈 界面隐藏** — 一键隐藏标签栏、状态栏、仓库名称、滚动条、侧边栏按钮、工具提示、文件浏览器按钮、搜索建议、搜索结果匹配数、操作提示、阅读视图属性。
- **📐 排版与间距** — 独立控制正文行高、段落间距，支持两端对齐（Justify）及单词间距微调。
- **📋 列表与序号系统** — 自定义有序/无序列表的宽度、字号、缩进指示线偏移。
- **📖 编辑与阅读独立布局** — 分别设置编辑模式和阅读模式的最大宽度，阅读模式可独立使用衬线字体及英文断字。
- **🧘 极简交互** — 侧边栏按钮悬停展开（小圆点模式）、标签页下划线高亮、仓库切换器 5 种布局风格（含悬停展开、仅图标、完全隐藏等），并支持强调色跟随与悬浮动画。
- **🎨 统一圆角与材质** — 全局控制弹窗、面板、图片、视频、嵌入块、代码块等的圆角大小；弹窗支持毛玻璃效果（背景模糊）及透明度调节。
- **🔮 毛玻璃效果** — 全局总控开关，一键启用/禁用所有毛玻璃效果（弹窗、命令面板、引用块、顶栏、Excalidraw 工具栏等）。
- **✍️ 编辑器细节** — 标题等级标签、标题虚线、标题折叠箭头颜色、水平线多种样式、标签页高度、文件列表前缀圆点、隐藏根文件夹、移除表格前空行（性能优化）、行号显示模式等。
- **🚀 进阶功能** — 聚焦段落模式、多列布局（2~3 列）、代码块背景对比度与圆角、代码块复制按钮位置、标签尺寸与悬停放大、嵌入块边框颜色与内边距、顶栏半透明/毛玻璃、顶栏分割线、折叠指示器样式与动画、装订线背景、弹窗动画类型、右键菜单密度、Dataview 表格行高与表头加粗、Dataview 卡片圆角、日历单元格圆角与日期标记样式、Canvas 卡片圆角同步、Excalidraw 工具栏毛玻璃等。
- **📝 排版增强** — 高亮标记样式（圆角药丸、毛玻璃、下划线）、斜体/粗体特殊渲染（斜体加下划线、粗体加背景色/下划线）、链接悬停下划线动画、正文首行缩进、阅读模式首字下沉、中文与英文/数字自动间距。
- **📋 列表强化** — 任务列表复选框样式（圆点/方形）、嵌套列表自动切换标记、列表项卡片模式。
- **✨ UI 交互细节** — 命令面板毛玻璃、侧边栏文件图标按类型彩色、阅读模式标题居中、标签页关闭按钮悬停放大、面包屑导航样式（药丸/半透明）等。
- **✍️ 编辑器增强** — 光标颜色跟随强调色、当前行左侧竖线指示、选中文本背景跟随强调色、自动补全菜单毛玻璃、括号/标签匹配高亮。
- **📖 阅读模式增强** — 脚注悬停预览毛玻璃、表格单元格自动换行、图片添加柔和阴影、预设彩色背景块（通过 callout 语法）。
- **🔧 设置入口** — 可自由移动 Obsidian 原生设置按钮（侧边栏左下角/状态栏/标签栏），侧边栏折叠时自动适配至状态栏。
- **⚙️ 兼容性与性能** — 平滑过渡动画开关、界面饱和度/对比度微调。

## 📦 如何安装

### 从 Obsidian 社区插件市场安装（待上架）

1. 打开 Obsidian，进入「设置」→「社区插件」→「浏览」。
2. 搜索 **Pure Hide**。
3. 点击安装并启用。

### 手动安装

1. 从 [GitHub Releases](https://github.com/yuangwu/obsidian-pure-hide/releases) 下载最新版本的 `main.js`、`manifest.json` 和 `styles.css`。
2. 将这三个文件放入您的 Obsidian 仓库中的 `.obsidian/plugins/pure-hide/` 文件夹（若不存在则创建）。
3. 重新加载 Obsidian，在「设置」→「社区插件」中启用 Pure Hide。

## 📖 使用方法

### 1. 首次启动

安装并启用插件后，Obsidian 会弹出一个**许可证信息**窗口，展示 AGPL-3.0 开源协议摘要及双重许可说明。您可以直接关闭窗口，无需任何操作即可正常使用全部功能。

如果您想再次查看许可证信息，可通过命令面板执行 `Pure Hide: 查看许可证信息`。

### 2. 基础配置

打开 **设置 → 插件选项 → Pure Hide**，您将看到按功能分组的所有可调选项。每个选项都配有清晰的描述，数值型参数支持滑块调节，实时生效。

### 3. 快速命令

插件提供多个内置命令（可通过命令面板调用）：

- `Pure Hide: 切换状态栏显示`
- `Pure Hide: 切换标签栏显示`
- `Pure Hide: 查看许可证信息`
- `Pure Hide: 支持开发者 / 打赏`

### 4. 设置按钮位置管理

插件可以移动 Obsidian 原生的设置按钮（齿轮图标）到您喜欢的位置：

- **侧边栏左下角**（默认）
- **状态栏**
- **标签栏**

当侧边栏折叠时，若选择“侧边栏左下角”，按钮会自动移至状态栏以保证可见。
